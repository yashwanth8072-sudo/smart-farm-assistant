# Contributing

Thanks for contributing to SMART FARM ASSISTANT.

1. Open an issue describing the bug or improvement.
2. Create a focused branch and keep changes small.
3. Add or update tests for changed behavior.
4. Run `pytest -q` and ensure tests pass.
5. Document API or architecture changes.
6. Submit a pull request describing motivation, implementation, and validation.

Do not commit secrets, credentials, real farm personal data, or unlicensed datasets. Keep physical actuation disabled in tests. Animal deterrence features must be humane and lawful.
